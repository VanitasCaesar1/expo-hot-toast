# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep feedback about the work. Harassment,
insults and personal attacks are not welcome in issues, pull requests, discussions
or anywhere else the project lives.

To report a problem, contact the maintainer, VanitasCaesar1, through their GitHub
profile. Reports are read in confidence. The maintainer may remove comments, lock
threads or block accounts that break this code.
